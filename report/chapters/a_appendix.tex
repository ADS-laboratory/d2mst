\chapter{Development Environment}

The project provides a development container so that the required environemtn can be set
up automatically. The configuration is stored in the \texttt{.devcontainer/} directory and
is intended to be used with Visual Studio Code and the Dev Containers extension.

After the container has been created, the project can be compiled and tested from its root
directory:

\begin{verbatim}
gleam build
gleam test
gleam run
\end{verbatim}

The \texttt{gleam test} command runs the complete automated validation suite. The
\texttt{gleam run} command starts the interactive demonstration, which creates a graph,
runs GHS, and allows topology events to be applied in successive rounds.
